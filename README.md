# Sales-Analysis-System
This project uses a NumPy array containing product-wise sales data for each day of the week. It was created to practice NumPy concepts by applying them to a practical project.

 NumPy Concepts Used

* NumPy arrays
* 2D array indexing
* Array slicing
* `np.where()`
* `np.sum()`
* `.astype(int)`
* String handling with `.strip()` and `.title()`
* User input
* `if-elif-else`
* `while` loop
* Basic exception handling
